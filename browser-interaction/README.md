# Browser Interaction

浏览器交互技能集，内容汇聚自三个项目：

- ChromeDevTools/chrome-devtools-mcp
- microsoft/playwright-cli
- lackeyjb/playwright-skill

按工具分两组：

- `chrome-devtools/`：`chrome-devtools-cli` 命令手册，外加无障碍、Cookie、LCP、内存泄漏四个调试工作流。要用 DevTools 调页面时，先读对应目录的 SKILL.md。
- `playwright/`：`playwright-cli` 交互命令手册；`playwright-script` 脚本自动化（含 API_REFERENCE 与 run.js）。要写脚本、跑自动化时读它。

用法：先读对应子目录的 `SKILL.md`，需要细节再读其 `references/`。
